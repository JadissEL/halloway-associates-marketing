# 02 — Stratégie

**EN:** Productized studio: sell a fixed kit fast, retain via care plan, expand city/niche later. Pre-GTM = structure only.

**FR :**

## Modèle économique

```text
Acquisition (plus tard) → Audit gratuit 15 min → Kit payé → Delivery 7–14 j → Care mensuel + upsells
```

| Levier | Description |
|--------|-------------|
| **Acquisition** | Outbound + réseau local + referral *(dormant jusqu’au GO GTM)* |
| **Conversion** | Mini-audit « 3 freins » → devis kit |
| **Delivery** | Usine de templates par niche, customisée |
| **Rétention** | Care €49–99 / mois + pages / SEO / landing |
| **Long terme** | Devenir le partenaire digital par défaut d’une ville, puis scaler niches/villes |

## Horizons

| Horizon | Focus |
|---------|--------|
| **H0 — Structuring (actuel)** | Docs, offre claire, site, assets, OS dry-run, légal/finance stubs |
| **H1 — Soft GTM** | 5–10 audits manuels, 2–3 kits livrés, preuves réelles |
| **H2 — Scale local** | Outbound assisté + referrals, care portfolio |
| **H3 — Expansion** | Nouvelle ville / niche factory |

## Non-goals (toujours)

- Bulk scrape / CAPTCHA bypass  
- Cold WhatsApp / SMS blast  
- Marketplace  
- Checkout Stripe obligatoire au MVP (demande de devis suffit)  

## North-star (pre-GTM)

Un inconnu comprend l’offre en **&lt; 5 secondes** sur le site ; le fondateur peut **opérer** (delivery + devis) sans improvisation.
