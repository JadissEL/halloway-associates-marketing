## 1) Philosophy (non-negotiable)

Follow-ups exist to **create clarity and make it easy to say yes or no** — not to pressure, guilt, or spam.

1. Respect > persistence  
2. Value in every touch  
3. Adult-to-adult tone  
4. One ask per message  
5. Short by default (email 50–120 words; hard max ~180; DM shorter)  
6. Specificity beats cleverness  
7. Exit gracefully  
8. Human handoff on interest (auto-draft OK; **auto-send replies = OFF**)  
9. Truthful — no fake personalization or scarcity  
10. Compliance-first — unsubscribe absolute; no SMS cold follow-ups  

### Brand voice

International-professional; Greek startup; outcomes = paid bookings, fewer unserious DMs, owned revenue. Never growth-hack blast tone.

### Forbidden

Empty bumps · guilt · fake personalization · link stacks early · “final notice” · daily FUs · multi-channel same day · arguing with “no” · post-unsubscribe contact · niche pitch drift · second cold thread while one open

## 2) Strategy & stages

**Goal:** ignore → curious → sees kit → books audit / replies.

| Stage | Job | Status / action |
|-------|-----|-----------------|
| 0 Cold | New angle + soft CTA | sequence active |
| 1 Soft open | Lower friction (never “saw you opened”) | continue, shorten |
| 2 Curious | Answer + proof + book | pause seq · warm |
| 3 Interested | Kit + next step | pause · **hot** |
| 4 Audit booked | Confirm + prep | pause |
| 5 Negotiation | Proposal; no nagging | proposal_sent |
| 6 Won | Onboarding; stop sales FUs | won |
| 7 Lost / No | Close; 180d or suppress | lost |
| 8 Nurture | One 60–90d revisit | nurture |

### Angle rotation

Pain → Product → Proof → Contrast → Ease → Peer (no fake logos) → Breakup  

### Channels

1. Email primary · 2. IG/LinkedIn assisted · 3. WhatsApp/SMS only consent · 4. Comments light only  

**Multi-channel:** not same person, same day. Reply on IG → pause email, own that thread.

## 3) Cadence

| Step | Day | Type | Angle |
|------|-----|------|-------|
| E1 | 0 | Intro | Pain |
| E2 | 2–3 | Value | Product / offers |
| E3 | 5–6 | Proof | Kit demo |
| E4 | 8–9 | Objection | Managers/platforms |
| E5 | 12–14 | Breakup | Close loop |

Max **5** cold emails/cycle. OS delays: `0 / 3 / 3 / 3 / 4`. Prefer **Tue–Thu**. Hot replies: same day.

| Signal | Action |
|--------|--------|
| Opens, no reply | Silent angle change; shorter; yes/no CTA |
| Kit click, no reply | 48–72h clicked template |
| Busy / later | Timing ask → one nurture 60d default |
| Not interested | One close · suppress/180d |
| OOO | Pause to return+1bd |
| Bounce | Stop · enrich once |
| Unsub | Immediate absolute suppress |

## 6) Objection handling (in-thread; pause sequence)

| Objection | Approach | Do not |
|-----------|----------|--------|
| Has manager | Kit cuts scheduling/payment load; manager keeps relationships | Attack manager |
| Already get brand deals | Serious brands prefer clear booking/media kit; filter unserious | Promise Nike |
| Has Linktree | Linktree ≠ paid booking + intake + offers | Insult Linktree |
| Too expensive | Hours saved + one paid session ROI; scope options | Desperate discount |
| Send a deck | 1 kit link + 5-line summary + 15-min offer | 20-page PDF first |
| Not now | Ask timing; one revisit | Weekly pings |
| vs freelancers | Productized kit + monetization + consulting | Bash freelancers |
| “Is this spam?” | Honest; instant opt-out | Defensive |
| “Not an influencer” | Pivot creator/coach/personal brand **or** stop if ICP miss | Force-fit |
| Silence after interest | One proof nudge + breakup | 8 bumps |

Tone: curious, precise, brief. End with question or next step.

| Signal | SLA | Action |
|--------|-----|--------|

| Pricing? | Same day | Band + included + audit to tailor |
| Call? | Same day | Calendar + timezone |
| Detailed Qs | Same day | Bullet answers |
| Contract | Same day | Proposal + 50% deposit terms |

Always: mirror channel · confirm monetization goal (collab/lessons/meets) · one next step · log pipeline.  
Never: 4+ day silence · generic non-influencer brochure · over-automate.

## 8) Breakup & silence

Breakup must: acknowledge busy · one-line offer · binary close · no bitterness.  
After breakup + silence: **stop** · status exhausted · cool-down **90–180 days**.  
No 6th/7th cold email. Optional one different-channel touch (K) then suppress from active campaigns.

## 9) Personalization levels

| Level | When | Rule |
|-------|------|------|
| L0 Category | Weak data | “Creators drowning in DMs…” |
| L1 Niche | Known vertical | Fitness / beauty creator |
| L2 Public proof | Verified field only | Real coaching offer — **never fabricate** |
| L3 Relationship | Warm intro | Name introducer |

Cold automation = L0–L1 reliably; L2 only with verified data.

## 11) Outbound OS operational rules

| Rule | Requirement |
|------|-------------|
| Human reply | **Pause** sequence |
| Unsub / bounce / complaint | Pause + suppress |
| Classify | Hot → Pipeline (`hot`) |
| Reply drafts | Suggested draft OK; **human must send** |
| Task due | Interested = same day; proposal nudges = Day 3 & 7 |
| Caps | Follow-ups count toward mailbox daily caps |
| Pending | Never >1 pending outbound to same lead |
| Threading | Sequence steps = new emails OK; conversational replies = in-thread |

Documented for operators; dry-run until unlock. See also `outbound-os/docs/OUTREACH_COPY.md`.

### Pipeline playbook (post-reply)

1. Classify → set stage (`hot` / `audit_booked` / `proposal_sent` / `won` / `lost`)  
2. Pause campaign sequence for that lead  
3. Use reply macros from `influencers/reply_*.md`  
4. Create follow-up tasks (same day / D+3 / D+7)  
5. On won: stop sales FUs; referral ask only after delivery success  

---

## 12) Metrics (quality, not vanity)

- Reply rate by step E1–E5  
- Positive reply rate  
- Unsubscribe/complaint rate (must stay tiny)  
- Audits booked from follow-ups  
- Breakup → late yes  
- Time-to-first-response on hot leads  

If unsubscribes spike: **shorten, soften, reduce frequency** — do not push harder.
