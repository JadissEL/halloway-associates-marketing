# SOP-10 — Referral ask

| Meta | Value |
|------|--------|
| **Purpose** | Systematically ask happy clients for introductions. |
| **Owner role** | Success / care |
| **Last updated** | 2026-10-31 |
| **Status** | `active` |
| **Non-goals** | Paid referral spam; pressure. |

**Trigger:** CSAT ≥4 or care month 2  
**Inputs:** Client goodwill  
**Outputs:** Intro or soft no  
**SLA:** Ask once; follow-up once at +14 d  

### Steps
1. Thank for collaboration  
2. Ask: “Who else nearby (same niche/city) should hear about this?”  
3. Offer to send a short blurb they can forward  
4. Log referral lead  

### Quality bar
Ask only after clear value delivered.

### Failure modes
- Asking during disputes
