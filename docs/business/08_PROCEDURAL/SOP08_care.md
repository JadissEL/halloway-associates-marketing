# SOP-08 — Care-plan monthly loop

| Meta | Value |
|------|--------|
| **Purpose** | Retain clients with scoped monthly updates. |
| **Owner role** | Success / care |
| **Last updated** | 2026-10-31 |
| **Status** | `active` |
| **Non-goals** | Unlimited redesigns inside care fee. |

**Trigger:** Care subscription active / monthly anniversary  
**Inputs:** Client change requests (≤ N/mo)  
**Outputs:** Changelog note + invoice  
**SLA:** Acknowledge ≤48 h; ship small changes ≤7 d  

### Steps
1. Collect requests (cap 2–4 small edits)  
2. Reject out-of-scope → quote add-on  
3. Apply updates  
4. Notify client  
5. Bill next month in advance  

### Quality bar
No silent scope inflation.

### Failure modes
- Treating care like a new kit each month
