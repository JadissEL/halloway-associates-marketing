# SOP-06 — Design / build / QA / launch

| Meta | Value |
|------|--------|
| **Purpose** | Produce kit to design bar and launch safely. |
| **Owner role** | Delivery / web production |
| **Last updated** | 2026-10-31 |
| **Status** | `active` |
| **Non-goals** | Greenfield redesign of studio site; endless revisions. |

**Trigger:** Intake complete  
**Inputs:** Brief, niche demo pattern, brand tokens client chose  
**Outputs:** Live site + launch checklist done  
**SLA:** First preview ≤7 d; launch ≤14 d  

### Steps
1. Clone niche skeleton (salon/café/avocat/livreur patterns)  
2. Apply client content + visuals  
3. Desktop-first layout check ≥1024px  
4. Mobile adaptation  
5. Forms: loading/empty/success/error  
6. Internal QA (`10_DESIGN` checklist)  
7. Client review round (1 structured)  
8. Domain + go-live  
9. Remainder invoice  

### Quality bar
Design review checklist 100% critical items; no broken CTA.

### Failure modes
- Unscoped revision loops  
- Launch with broken form
