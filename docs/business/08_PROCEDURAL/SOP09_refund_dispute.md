# SOP-09 — Refund / dispute handling

| Meta | Value |
|------|--------|
| **Purpose** | Resolve money/quality conflicts without destroying standards. |
| **Owner role** | CEO · Ops |
| **Last updated** | 2026-10-31 |
| **Status** | `draft` (align with final CGV) |
| **Non-goals** | Automatic full refunds for change-of-mind after delivery. |

**Trigger:** Formal complaint or refund request  
**Inputs:** Proposal, invoices, messages, delivered work  
**Outputs:** Written resolution  
**SLA:** Acknowledge ≤2 business days  

### Steps
1. Pause public blame; gather facts  
2. Compare delivered vs written scope  
3. If our miss → fix at no charge or partial refund  
4. If client scope/assets miss → offer path forward, no full refund of deposit for work done  
5. Document outcome in client folder  

### Quality bar
Written decision; CGV-aligned when legal stubs finalized.

### Failure modes
- Emotional instant refunds  
- Ghosting the client
