# SOP-03 — Proposal + pricing

| Meta | Value |
|------|--------|
| **Purpose** | Send clear written offer inside price bands. |
| **Owner role** | Sales / audit · CEO accountable |
| **Last updated** | 2026-10-31 |
| **Status** | `active` |
| **Non-goals** | Custom SOW novels; discounts >15% without note. |

**Trigger:** Fit after audit  
**Inputs:** Audit notes, niche, scope  
**Outputs:** Proposal PDF/md + price + milestones  
**SLA:** ≤48 h after audit  

### Steps
1. Pick band position (€790 / mid / €1490) from complexity  
2. List included kit items; list out-of-scope  
3. Add booking add-on if needed  
4. State 50/50 (or 40/60) payment  
5. State 7–14 day clock starts at complete intake  
6. Send + calendar follow-up +3 days  

### Quality bar
No ambiguity on deliverables or money.

### Failure modes
- Vague “we’ll see” scope  
- Underpricing to win
