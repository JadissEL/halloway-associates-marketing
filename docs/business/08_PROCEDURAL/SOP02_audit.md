# SOP-02 — Free 15-min audit

| Meta | Value |
|------|--------|
| **Purpose** | Deliver 3 concrete freins; book next step without hard sell. |
| **Owner role** | Sales / audit |
| **Last updated** | 2026-10-31 |
| **Status** | `active` |
| **Non-goals** | Closing payment on the call; free full redesign. |

**Trigger:** Audit booked or form submitted  
**Inputs:** URL/IG, niche, notes  
**Outputs:** Scorecard + 3 freins + proposal yes/no  
**SLA:** Reply ≤24 h; call ≤15–20 min  

### Steps
1. Open site/IG/Google  
2. Run 10-point scorecard (`outreach/audit-checklist.md`)  
3. Name 3 freins (conversion, trust, contact)  
4. Ask goal & timeline  
5. If fit → “I’ll send a written proposal in 48 h”  
6. Log notes in CRM-lite or OS  

### Quality bar
Prospect repeats at least one frein back.

### Failure modes
- Pitching features instead of freins  
- Overtime rabbit holes
