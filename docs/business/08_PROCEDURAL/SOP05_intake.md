# SOP-05 — Client intake

| Meta | Value |
|------|--------|
| **Purpose** | Collect complete brief before build clock. |
| **Owner role** | Delivery |
| **Last updated** | 2026-10-31 |
| **Status** | `active` |
| **Non-goals** | Starting design on half-empty briefs. |

**Trigger:** Deposit received  
**Inputs:** `/intake` form or equivalent  
**Outputs:** Complete intake checklist  
**SLA:** Chase missing assets day 2 and day 5; clock pauses if incomplete  

### Steps
1. Client submits `/intake`  
2. Verify logo, photos, services, prices, hours, booking pref  
3. Confirm colors/ambiance  
4. Mark intake complete → start build clock  
5. If blocked → notify client clock paused  

### Quality bar
Checklist in `business/06-delivery/checklist-intake.md` all required boxes.

### Failure modes
- Accepting “photos later” then inventing content
