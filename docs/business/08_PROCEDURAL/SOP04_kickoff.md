# SOP-04 — Contract / payment kickoff

| Meta | Value |
|------|--------|
| **Purpose** | Start project only after written OK + deposit. |
| **Owner role** | Ops / finance · Sales |
| **Last updated** | 2026-10-31 |
| **Status** | `active` |
| **Non-goals** | Starting build on verbal promise alone. |

**Trigger:** Client accepts proposal  
**Inputs:** Signed/OK email, deposit proof  
**Outputs:** Project folder + invoice #1 + intake link  
**SLA:** Invoice same day; intake link with payment  

### Steps
1. Issue invoice `HA-YYYY-NNNN` (deposit)  
2. Confirm payment cleared  
3. Create client folder structure  
4. Send `/intake` link + deadline for assets  
5. Mark pipeline = won / intake  

### Quality bar
No production hours before deposit (exception: CEO-logged).

### Failure modes
- Building while “payment pending”
