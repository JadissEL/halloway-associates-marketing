# Niche kit template

Copy this folder to `src/portfolios/<slug>/` and fill:

| Piece | File / route |
|-------|----------------|
| Data (offers, persona) | `data.js` |
| Layout + nav | `Layout.jsx` + `kit.css` |
| Home | `pages/Home.jsx` |
| Offers | `pages/Offers.jsx` |
| Book + intake | `pages/Book.jsx` |
| Success | `pages/Success.jsx` |
| Media kit | `pages/MediaKit.jsx` |
| Link-in-bio | `pages/Links.jsx` |
| Dashboard | `pages/Dashboard.jsx` |
| Card | `pages/Card.jsx` |
| Legal | `pages/Legal.jsx` |
| This README | customize for client |

Wire routes in `src/App.jsx` under `/portfolios/<slug>/*`.  
See `docs/PORTFOLIO_SYSTEM.md`.
