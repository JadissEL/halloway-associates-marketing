# Outbound OS — follow-up operations

Mirrors [`docs/OUTREACH_FOLLOWUPS.md`](../../docs/OUTREACH_FOLLOWUPS.md) §11.  
**DRY_RUN / LAUNCH OFF** until founder unlock.

| Event | OS action |
|-------|-----------|
| Any human reply | Pause sequence for lead |
| Unsubscribe / bounce / complaint | Pause + suppression |
| Positive / interested classify | Pipeline → `hot`; suggest draft; **human sends** |
| Audit booked | Stage `audit_booked`; pause sales seq |
| Proposal sent | Stage `proposal_sent`; tasks Day 3 & Day 7 (`proposal_nudge`) |
| Won | Stage `won`; stop sales FUs |
| Lost / not interested | Stage `lost`; suppress or 180d |
| Caps | Follow-ups count toward daily mailbox caps |
| Queue | Never >1 pending outbound message per lead |

Sequence seed: **Influencer Digital Kit EN** (5 steps). Templates: `outreach/followups/influencers/`.
